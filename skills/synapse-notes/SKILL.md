# Notes

写给未来的自己。记下一个让自己停顿的瞬间，写清当时怎么判断、什么反馈改变了自己、下次准备怎样做。允许短、碎、琐细，也允许保留尚未想明白的问题。

| 笔记类型 | 打开 |
| --- | --- |
| 感触随笔、个人观察、观点与成长记录 | [references/growth.md](references/growth.md) |
| 一本书或一条书中规则怎样改变自己的选择 | [references/reading-notes.md](references/reading-notes.md) |
| 论文、实验、源码或工作反馈怎样改变自己的理解 | [references/research.md](references/research.md) |

## 共同规则

- 用用户提供的经历、语气和真实观察建立第一人称。区分当时的想法和现在的解释，保留尚未确认之处。
- 顺序从材料长出来。一次感触可以只有现场、变化或一个待查问题，有行动时把它写具体。默认用 Markdown，沿用用户指定的载体。
- 同一次线上故障，记“我当时为何误判、下次先测什么”用 Notes。面向同行解释“为何该机制导致尾延迟、怎样复现与验证”用 `synapse-tech-blog`。
- 需要离线 HTML 时从同一份记录排版。用户明确要求公众号适配时，打开 [references/wechat-layout.md](references/wechat-layout.md)。按用户明确要求执行外部同步或发布。
