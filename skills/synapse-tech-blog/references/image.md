# 文章技术插图

1. 动笔前写清这张图要让读者理解什么、画面里的对象与关系、读图顺序和来源位置。优先图解运行机制、状态迁移、因果差异或可核验结果。
2. **对照用同一坐标。** 先后流程、两轮请求或前后状态用上下对应行。并行实现、两条路径或方案取舍用左右等宽面板。对应组件镜像或对齐，标签与颜色保持同义。真实的分支、回边和不对称成本保留各自空间和方向。
3. 正常技术长文新图默认 16:9 横版，验证实际像素。用暖象牙底、深墨文字、克制的低饱和颜色（非背景色至多三种），短标签、薄线与清晰箭头。[参考图](../assets/blog-technical-figure-reference.png) 可作风格参照。用户指定载体比例和项目 `DESIGN.md` 优先。连续研究页读 [paper.md](paper.md)。
4. 证据图保留原始比例、标注、单位和归因。重绘要可追溯原始图号与链接，并可视觉核对。架构图用真实模块或源码符号，画清数据和控制方向。实验图注明基线、口径和条件，假设性示意明确标记。
5. 可编辑的工程图使用 `synapse` 的 Excalidraw 工作流。需要动效时使用其中的 Animation 工作流。生成栅格图时用当前环境的图像工具，Synapse 默认 Codex imagegen。保留渲染源或提示词于项目素材；交付已完成的图片与文章。
6. 图内默认英文标签。图下面用 `Figure N: description` 风格的短标题，再给具体说明和来源链接。图片 alt 描述画面。用实际渲染检查比例、裁切、箭头交叠、文字、图注与正文的对应。
