# 技术博客 HTML 排版

正文阅读页从 [Why.J Theater 博客模板](../templates/whyj-theater-blog.html)复制。中英文稿共用模板，按正文语种设置页面的 `lang`。

## 建立博客总目录

1. 在合集根目录准备 `index.html`。工作区已有 Why.J Theater 目录模板时，可复制后调整。填写页面标题、导语与底部配套材料。
2. 在「按主题」视图下按读者要解决的问题组织文章。每组用一个 `section.topic`，小组可用 `.topic-group`。在「按顺序」视图下说明每一组承接的知识，用 `ol[start]` 和 `li[value]` 保持跨组的阅读序号。两个视图共用文章标题和链接，条目可在 `data-keywords` 补充术语、项目名和缩写。
3. 各视图在 `.categories` 放分组导航，在 `.directory-content` 放文章列表。为各组设置页面内唯一的 `id`，使导航链接的片段与组 ID 对应。文章和附录使用相对路径。断网检查视图切换、搜索、分组跳转和窄屏阅读，并逐一核对文件链接。

目录页沿用正文模板的视觉风格，使用暖纸底、窄版心、衬线标题、细线分隔和低饱和橙色。HTML 自带样式和交互，离线使用本机可用字体。

## 套用 Pretext 版式

1. 在模板副本中填写 `TITLE`、`META`、`LEAD` 和 `SECTIONS`。普通节用 `{ heading, body, callout }`。含引用或强调的正文用 `bodyHTML`，把章节回答的 Markdown 粗体呈现为 `<strong>`。将成本判断、边界与解释放到相关证据所在节的正文或 `callout`。需要收束时在参考文献前正常成节。由 DSL 渲染时保留段落层级与顺序。
2. 图像使用独立的 `{ image, caption, description, source, alt }` 项，路径相对输出文件。`caption` 写短标题，`description` 写读图说明，`source` 链接原始证据，可用 `sourceLabel` 命名。图片和 HTML 图表本身就是放大入口。点击图面或聚焦后按 Enter、空格放大，按 Esc 关闭。用最终图像替换占位，生成提示词留在素材记录。
3. 保留内嵌 Pretext 库。需要调整文字测量时，确保字体和行高与 CSS 一致，每种文本与字体只准备一次，窗口变化时重算布局。点击阅读区时，在落点展开陶土色双环，环形扩散并在 560 毫秒内淡出。链接、图面和可操作控件沿用各自的点击行为。系统开启减少动态效果时跳过提示。保留 JavaScript 字符串分隔符并检查编辑后的模块能否解析。
4. 在浏览器打开交付件，检查桌面和窄屏的目录、正文、图片、缩放和代码块。需要离线阅读时断网检查。外置图与 HTML 一起交付，单文件要求下嵌入实际图像。

## 配置文章目录

模板根据 `SECTIONS` 中的章节标题生成文章目录。需要跨版本引用时，在章节中写明稳定的 `id`。标题较长时，可用 `tocLabel` 提供简洁的导航名称。在附录首节设置 `tocBreak: true` 可加一条分隔线。独立图和没有标题的续段沿用原有阅读顺序。

宽屏目录从正文分割线的高度起排，滚动时留在左侧并标出当前章节。窄屏把目录收进导语下方的粘滞按钮，跳转后自动收起。验收时检查起始对齐、章节深链接、滚动高亮、键盘操作和手机上的展开与收起。
