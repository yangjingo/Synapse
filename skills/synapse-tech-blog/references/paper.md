# 论文解读与 YJ Paper

## 单篇与论文簇

单篇先交代研究对象、原方法卡在哪、作者改变了哪一步及适用条件。按正文核对公式、符号、指标和实验对照，区分报告结果、推导和未验证假设。

多篇围绕同一个问题时，动笔前完成三个工作笔记：

1. **横向 taxonomy**。按共同目标、假设、机制、证据、边界比较。记录论文版本与原图或原文位置，只保留说明差异所需的维度。
2. **共同主线**。写出共同使用的数学对象、约束或设计原则，以及在什么条件下分叉。材料无法支持共同机制时收窄问题。
3. **解释缺口**。指出读者从一篇过渡到另一篇需要补的定义、推导或反例。自己的推导注明依据与成立条件。无法核实的连接标为待验证。

正文按概念依赖组织，先给理解公式所需的直觉，再用公式说明改变了什么。拿掉论文名后检查论证仍然能够成立。普通论文长文交付包含原始来源的 Markdown 或 HTML。

## 连续研究页

- 用户明确要 YJ Paper 或论文轮播时，默认按 4:5 竖版组织。用标题/TL;DR → 问题 → 机制 → 证据与边界 → 来源和讨论作为起点，按文章实际贡献调整页数与顺序。
- 先选每页的一句主张。配一张必要图或一条主公式，标明变量和操作含义。保持固定的版心、字号层级、单一低饱和强调色和安全边距。内容拥挤时拆页。
- 先看官方图、图注和正文。重绘保留拓扑、方向、同步边界与粒度，注明“据论文 Figure N 重绘”。仅依据正文时明确写“概念示意”。
- 交付前逐页检查可读性、顺序、数值和出处。可编辑页面保留可点链接。栅格末页列书目，交付说明附原始链接。
