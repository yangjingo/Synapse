# 公众号

开头先交代读者能认出的处境及问题。每一段推进一个观察、解释、证据或可执行判断，保持短段落和连贯阅读。区分事实、作者经验、可核查引用、编辑推断与虚构隐喻。

| 用户要的内容 | 打开 |
| --- | --- |
| 作者观点、长叙事、荒诞锐评或中心隐喻 | [references/essay.md](references/essay.md) |
| 读书笔记或 YJRule | [references/reading-notes.md](references/reading-notes.md) |
| 面向公众号改编技术文章、论文或项目复盘 | [references/technical.md](references/technical.md) |
| 公众号单栏 HTML、插图和富文本复制 | [references/layout.md](references/layout.md) |

先选一条写作主线。交付 HTML 时再读排版 reference，文本稿按用户要的格式交付。需要更新公众号后台时，以用户明确授权为准。
