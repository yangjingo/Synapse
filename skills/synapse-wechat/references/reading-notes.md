# 读书笔记与 YJRule

以一个现实问题说明这本书的哪条规则值得读。每条规则给出版本、章节或可核查原文，再写自己的理解、真实应用场景和失效边界。引文不可核实时用准确转述并说明出处范围。

明确要求 YJRule 时，采用以下阅读次序：

```text
规则编号 → 短原文或准确转述 → 中文观点 → 关键判断 → 理解与应用 → NOTE → 主插图
```

NOTE 写限制、反例或一个有证据的现实摩擦。缺个人案例时使用明确标注的假设例子。每条 Rule 可参考 280–500 个中文字符，篇幅由材料决定。明确需要插图时每条 Rule 用一张主图，放在 NOTE 之后，比例和复制方式见 [layout.md](layout.md)。
