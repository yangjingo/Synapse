# 公众号排版与复制

- [单栏文章模板](../assets/wechat-essay.html) 适用于观点稿和技术改编，按内容更换小节与图片。[读书笔记模板](../assets/wechat-reading-notes.html) 适用于 Rule 与 NOTE 结构。发布稿清理模板占位和空插图区。
- 正文使用单栏、左对齐与内联样式。关键字号、行距与边距避免依赖全局 CSS，复制节点的阅读顺序保持语义清楚。模板正文为 `12px / 1.95`、最大宽度 `632px`，用户的排版要求优先。普通段落可参考 45–90 个中文字符。
- 新作公众号主插图默认原生 16:9（如 1600 × 900），采用暖白、深墨、低饱和强调色。可比较的对象上下对齐、左右并列或按同尺度镜像。证据原图保留比例，可通过图注或邻近正文标出来源。独立技术图可调用 `synapse-tech-blog` 的图示 reference。
- HTML 预览用 `data:image/…;base64,…` 嵌入最终图片。复制只选文章节点、内联样式和图片。工具栏和脚本留在预览页。若编辑器不接收内嵌图，核对实际粘贴效果，再单独上传这些图片。
- 交付前约 390px 宽查看正文与图像是否溢出，检查复制内容、阅读顺序、来源链接与图片数量。编辑器内二次核对需实际粘贴验证。
