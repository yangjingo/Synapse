# 观点文章与荒诞隐喻

从一场具体处境开始。写清谁在什么约束下做了什么选择、谁承担后果，以及哪条直觉失效。随后给出一个具体判断。材料只够一条观点时，可以直接交付短评。

- 普通观点文可按场景 → 机制 → 假设或例子 → 适用边界推进。结尾回到现实处境，给一个读者用得上的判断。
- 荒诞观点文从可辨认的现实机制提取一个中心隐喻。隐喻与原机制一一对应。需要升级时，每次改变一个变量，比如成本、责任、时间或组织层级。
- 纪实材料里的对话、经历、数字和作者判断须有出处。虚构的寓言明确表现为隐喻。用约束与激励解释行动，避免把人物写成陪衬或反派。
- 长稿可参考 1,500–3,000 个中文字符。开头用少量短段让处境成立，中段每次转折增加一条因果关系，最后回到现实约束。保留材料原有的语气和克制感。
