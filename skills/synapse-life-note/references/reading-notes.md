# 读书笔记与 YJRule

从自己遇到的一个问题开始，写清书中的哪条规则触动了自己、原判断哪里变了。保留可核查的版本、章节或原文，再写实际应用、可能失效的场景和下一次尝试。引文不可核实时用准确转述并说明出处范围。

明确要求 YJRule 时，采用以下阅读次序：

```text
规则编号 → 短原文或准确转述 → 中文观点 → 关键判断 → 理解与应用 → NOTE → 主插图
```

NOTE 写限制、反例或一个有证据的现实摩擦。缺个人案例时使用明确标注的假设例子。每条 Rule 可参考 280–500 个中文字符，篇幅由材料决定。明确需要插图时每条 Rule 用一张主图，放在 NOTE 之后。
