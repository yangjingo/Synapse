# Talk Slides · 演讲幻灯片

## 讲给谁

给正在听讲、需要理解机制或做判断的听众。先确定听众已有的背景、可用时间和讲完希望他们记住的一句话。

## 怎么讲

1. **交代问题。** 让听众知道正在解决谁的问题、什么现象值得解释、为什么值得听。
2. **组织逐页推进。** 技术分享可按问题、机制、证据、适用边界展开。观点表达可按共同观察、主张、理由、反例展开。教学可按示例、练习、检验展开。
3. **把信息分配到页面与讲稿。** 一页讲清一个主要判断。保留能看清的图、必要的数字和来源，将额外细节放进讲稿、附录或技术博客。

## 交付前核对

- 标题、图和口播支持同一个判断。证据的范围和假设清楚，听众能复述结论及其适用条件。
- 检查实际播放顺序、字图可读性、链接和备注。用户已有模板或指定格式时沿用其要求。
- 同题还有技术博客时，由 [Tech Blog](../synapse-tech-blog/SKILL.md) 复用同一组数据与来源，按阅读顺序展开机制和验证细节。
