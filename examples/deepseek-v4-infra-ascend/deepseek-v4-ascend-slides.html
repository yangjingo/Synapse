Context Parallelism

Prefill 通过 zig-zag 切分分摊因果计算

CANN · Prefill CP zig-zag
  • 靠后的 query 消费更长的历史。CP 将前后的 chunk 配到同一 rank，缓解负载偏斜。
  • 各 rank 还要收集边界数据，并选出本地 chunk 需要的历史。
[Prefill 切分之后，跨 rank 的依赖仍要按逻辑序列补齐。]

Draft rejection

MTP 只发布已被 verifier 接受的缓存状态

CANN · Cache slots in a ring buffer
  • Draft 会在验证前写入临时位置。verifier 拒绝后缀时，下一步 Decode 需要回到已提交边界。
  • Cache 恢复应覆盖滑窗、indexer 状态和 compressor 的尾部状态。
[MTP 的回收边界由已接受的 token 决定。]
